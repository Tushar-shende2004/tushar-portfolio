# Tushar Shende — Personal Portfolio

A responsive personal portfolio with a clean, futuristic visual style: deep navy surfaces, cyan accents, subtle motion, and mobile-friendly layouts.

## Preview locally

No build tools or package installation are required.

1. Download or clone this repository.
2. Open `index.html` in a browser.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/ (root)**, then click **Save**.
5. Wait for GitHub Pages to finish publishing. The site URL will appear in the Pages section.

## Personalize

- Review project cards and replace generic links with the exact repositories you want to feature.
- Confirm the LinkedIn URL and update it if needed.
- Keep the profile information and skills accurate to your current experience.
